# Square Foot Printing

E-commerce and order management platform developed for **Square Foot Printing**.

The system allows customers to configure custom printing products, calculate pricing, upload artwork, place orders, make payments, and track their orders online.

## Main Features

- Custom product configurators
- Dynamic product pricing
- Retail and wholesale customer pricing
- Production-type minimum order pricing
- Shopping cart and checkout
- Artwork/file uploads
- Online order tracking
- Customer accounts
- Admin dashboard
- Order management and production statuses
- Centralized pricing management
- MongoDB-based pricing overrides
- Stripe payment processing
- Stripe credit/debit card payments

## Product Categories

- Banners
- Displays
- Advertising Flags
- Large Format Printing
- Rigid Signs
- Stickers
- Printed Fabric
